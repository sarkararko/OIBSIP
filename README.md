# 🍕 PizzaCraft – Full-Stack Pizza Delivery & Inventory Management System

PizzaCraft is a production-grade full-stack pizza ordering and inventory management platform developed as part of my internship task at Oasis Infobyte.

The application provides separate User and Admin roles, pizza customization, order management, inventory tracking, real-time order status updates, payment integration, and automated low-stock notifications.

---

## 📌 Oasis Infobyte Internship Task

**Track:** Web Development & Designing  
**Level:** Level 3 – Advanced  
**Task:** Pizza Delivery Full-Stack Application  

### Task Objective

Build a production-grade, full-stack pizza ordering and inventory management platform with separate Admin and User roles, real-time order tracking, payment integration, and automated stock notifications.

---

# 🚀 Features

## 👤 User Side

- User registration with email verification
- Secure user login
- JWT-based authentication and authorization
- Forgot password functionality
- Browse available pizza varieties
- Custom Pizza Builder

### 🍕 4-Step Custom Pizza Builder

#### Step 1 – Choose Pizza Base
Users can select from multiple pizza base options.

#### Step 2 – Choose Sauce
Users can choose from available sauce options.

#### Step 3 – Choose Cheese
Users can select their preferred cheese type.

#### Step 4 – Choose Vegetables
Users can select multiple vegetable toppings.

---

## 🛒 Ordering System

- Add pizzas to cart
- View order summary before payment
- Review selected ingredients and pricing
- Place orders securely
- Payment gateway integration using Razorpay Test Mode
- Successful payment confirms the order
